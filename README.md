# Code With AI Quiz

A responsive multiple-choice quiz built with HTML, CSS, and vanilla JavaScript. The questions are based on AI, Git commit messages, unit testing, CSS organization, and time complexity.

## Features

- Displays one question at a time with four answer options.
- Tracks the score and question progress.
- Gives feedback after an answer and highlights the correct answer.
- Prevents a question from being answered more than once.
- Includes light and dark themes.
- Shows the final score and supports restarting the quiz.
- Responsive layout for desktop and mobile screens.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Answer the questions and try the theme toggle and restart button.

No build step, framework, database, or package installation is required.
